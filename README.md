# 🌟 مُحرر طيف (Taif IDE)

> **بيئة تطوير متكاملة، ذكية وخفيفة، مُصممة خصيصاً لدعم وتطوير البرمجيات بلغة البرمجة العربية "ألف" (Alif Language) على أنظمتي أندرويد ولينكس.**

مُحرر طيف ليس مجرد تطبيق لتحرير النصوص، بل هو بيئة عمل برمجية متكاملة تدمج بين سهولة الاستخدام للمبرمجين والعمق التقني في المعالجة. يوفر التطبيق تجربة تطوير فريدة تعتمد على أدوات ذكية مُدمجة لتبسيط كتابة البرمجيات باللغة العربية وتنفيذها لحظياً.

---

## ✨ المزايا البرمجية والتشغيلية

* **دعم لغة ألف وتلوين الشفرة:** يضم المحرك قواعد مخصصة لتلوين الشفرة البرمجية (Syntax Highlighting) والتعرف الذكي على الكلمات المفتاحية، الدوال المبنية، والنصوص بلغة ألف.
* **لوحة المفاتيح البرمجية "طيف":** يحتوي التطبيق على لوحة مفاتيح مُدمجة ومخصصة لتسهيل كتابة الرموز البرمجية والأقواس الشائعة، مع ميزة تحريك المؤشر عبر سحب زر المسافة أفقياً وعمودياً.
* **بيئة الأوامر والطرفية (Terminal):** طرفية مدمجة تتيح تشغيل الأكواد واستعراض المخرجات فورياً، بالإضافة إلى دعم مفسر أوامر داخلي للأوامر الأساسية باللغتين العربية والإنجليزية مثل (`عرض / ls`، `انتقل / cd`، `مسح / clear`).
* **إدارة ذكية للملفات وحفظها:** يدعم التطبيق الحفظ التلقائي لمنع فقدان البيانات، مع توفير واجهة لإدارة الملفات النشطة وتعديل خصائصها كأذونات القراءة والكتابة.
* **مشاركة الكود البرمجي:** ميزة تصدير الملفات البرمجية على هيئة صور منسقة بدقة عالية (PNG) لتسهيل مشاركتها عبر المنصات المختلفة.
* **التحديث التلقائي الذكي:** نظام متكامل لفحص وجود إصدارات جديدة للتطبيق عبر مستودع GitHub وتثبيتها برمجياً وبشكل مباشر.

## 🏗️ الهيكل البرمجي والمعمارية التقنية

تم بناء المشروع باستخدام إطار العمل **Flutter SDK**، مع الاعتماد على معمارية مقسمة بحسب الميزات (Feature-First Architecture) لضمان سهولة التوسع والتعديل:

```text
lib/
├── core/                  # المكونات المشتركة والخدمات العامة للتطبيق
│   ├── models/            # نماذج البيانات الأساسية للمشروع
│   ├── providers/         # إدارة الحالات العامة (المساحة، الإعدادات)
│   ├── services/          # خوارزميات إدارة الملفات، التحديثات، والمشاركة
│   └── theme/             # الألوان، الخطوط العربية، والسمات البصرية المدمجة
├── features/              # الميزات الأساسية للتطبيق
│   ├── editor/            # واجهات المحرر، الثيم الخاص بلغة ألف والقصاصات البرمجية
│   ├── keyboard/          # لوحة المفاتيح المخصصة ومنطق التحكم بالمؤشر
│   └── terminal/          # الطرفية المدمجة ومفسر الأوامر
└── generated/             # الملفات المولدة تلقائياً لدعم التدويل واللغات (Localization)
